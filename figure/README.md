# Tutorial figures

These PNG images illustrate the original root README workflow. They are static reference images, not bundled example data or results that validate a new analysis.

| Files | Illustration |
| --- | --- |
| `16S.png`, `RNA.png` | Original tutorial context for microbial profiling |
| `circle.png`, `violin.png` | Group abundance visualizations |
| `pcoa.png` | Bray-Curtis principal coordinates display |
| `fs1.png`, `fs2.png`, `fs3.png` | Feature selection and exploration figures |
| `heatmap.png` | Cluster/channel heatmap |
| `cor.png` | Correlation and Mantel visualization |
| `roc.png`, `conf.png` | Classification diagnostics |
| `dot.png` | Flow cytometry channel plots |

These files are referenced from [`README.md`](../README.md). The source repository provides no machine-readable dataset or full provenance for reproducing these exact images. New plots are written to user-supplied output directories rather than this folder; compare input assumptions and numerical checks, not visual resemblance alone.
